## 家宽 RDP 和代理、普通 VPS 差在两件事

一件是 IP 的归属类型，另一件是整台机器的环境变量。

普通 VPS 的 IP 来自数据中心，在 ipinfo 这类库里被标成商业或托管类型，平台的反欺诈系统对这类网段有现成的名单。住宅 IP 由运营商分配给家庭地址，库里显示的是 ISP 住宅属性，部分还带双 ISP 标记。这是第一层差别。

第二层更容易被忽略：代理只换了出口 IP。你本地还是中文 Windows、东八区时间、中文输入法、本地字体库，浏览器指纹、Canvas、WebGL 全是原来那套。平台风控看的从来不只是一个 IP。远程桌面连接的是一台完整的美国 Windows 机器，系统语言、时区、字体、浏览器行为都在那台机器上，本地电脑只负责显示画面。

所以家宽 RDP 解决的问题是“整套环境看起来像美国本地用户”，而不只是“出口 IP 在美国”。

sixtynet 这边，官网产品页只写了“Residential IP”，没有标明上游运营商。第三方测评里出现过 Cox Communications 和 AT&T Mobility 的网段，ipinfo 查出来是双 ISP 属性，但这些是测评方的观察，不是官网承诺，下单前最好自己拿测试 IP 查一遍。

## 配置怎么选：内存和带宽的真实分界

单人轻量用 2G 内存能装上 Windows，但只能单窗口轻活；4G 是单人日常的稳妥档；多账号、自动化脚本、多人共用才需要 8G。带宽同理，端口大小不代表你能跑满，月流量才是真约束。

先说内存。Windows 系统本身就要吃掉 1G 以上，2G 的机器开一个 Chrome 再挂个后台工具就接近满负荷，能跑，但没有余量。行业里对这件事有两套口径：一类教程说单人日常（管账号、浏览网页、处理邮件）4G 入门版完全够用，另一类测评建议 RDP 场景直接上 8G 内存。两套说法对应的是不同使用强度，不是谁对谁错。

落到 sixtynet 的档位上：

- 一个人用，开浏览器加一两个账号后台 → Residential-STARTER 的 2G 是底线，能加钱就上 4G 的 MICRO
- 同时挂多个账号、跑自动化脚本、或者两三个人共用一台 → 8G 的 MEDIUM
- 只做轻量验证、看看 IP 合不合用 → STARTER 够了

再说带宽。sixtynet 的端口从 2Gbps 起，看起来很大方，但月流量 5TB 是另一道限制，摊到每天约 170GB。单路 6Mbps 码率的直播大约每小时 2.7GB，5TB 能撑一千八九百小时，单人日常和单路推流完全够；多路推流、频繁传大文件，就得往 10TB 的 MICRO 走。

端口大带来的实际好处是峰值不排队，不是让你月月跑满。真按 2Gbps 跑满，5TB 的流量几个小时就用完了。

还有一件事官网没写清：是否提供 Windows 模板和授权。第三方测评显示这些机器是 KVM 虚拟化，理论上可以自己挂 ISO 装 Windows，但授权和驱动要自己解决。买之前问一句客服，比装到一半发现没授权强。

## 国内怎么连：直连 3389 不行，得走中转

从国内直接连美国的 3389 端口，延迟高、丢包、晚高峰经常连不上，这是所有美国住宅 RDP 的通病，不是 sixtynet 一家的问题。

常用的三条路，按稳定性排：

**1. 自建 CN2 GIA 中转（最稳）**

准备一台回国有优化线路的 VPS，装 3x-ui 面板，添加入站时协议选 TCP、监听一个随机端口（不要用 3389），目标填美国机器的 IP 和 3389。确认 Xray 显示运行中之后，本地 `mstsc` 的计算机栏填 `中转服务器IP:端口`，账号密码还是美国那台的。Mac 用 Microsoft Remote Desktop，PC 名称同样填中转 IP 加端口。

用随机端口是为了减少被扫描和暴力破解的概率，这一步别省。

**2. 公用中转服务（最省事）**

在中转平台充值，加一条转发规则，入口选中转入口，目标填住宅 IP 和 3389，然后把客户端里的 IP 和端口替换掉就行。缺点是线路公用，遇到攻击或拥堵会不稳。成本上，市面上有 3 个月 25 元这种起步档，比自建一台 VPS 便宜。

**3. 链式代理（最省设备）**

在 Shadowrocket、Nekobox、v2rayN 里设一个前置节点，再让住宅节点走前置。稳定性全看前置节点质量，适合已经有节点、只想快速验证的人。

这三条路都要额外花钱或额外维护。算总成本的时候，别只算 sixtynet 那 260 美元。

## 三个只写在小字里的限制

第一个是 80 和 443 端口不开放。官网在住宅系列的产品页上明确写了，原因是 IP 风控。想在上面挂网站、跑任何依赖 443 的服务，直接不行。远程桌面走 3389，不受影响，但你得知道自己买的是什么。

第二个是退款规则不一致。IRVINE-PRO 系列的产品页写明，这款产品的退款只能退到网站余额，不是原路退回现金。其他系列官网没有明说退款政策，下单前应当核对条款。整个住宅 IP 行业的普遍情况是资源成本固定、商家通常不支持退款，先小额验证再续费是更稳的顺序。

第三个是库存和流动性。住宅 IP 依赖真实的家庭宽带线路，一个物理地址能切出来的线路数量有上限，这类产品普遍存在库存约束，卖完要等。加上官网按年缴标价，一次性支出最低 260 美元，试错成本比月付产品高。

还有一条不算限制，但很容易误判：ipinfo、ping0 这类检测工具不是 100% 准确。有些机房 IP 会被误判成家宽，有些真实家宽会被标成 IDC，结果只能当参考。住宅 IP 也不等于永久免疫风控，使用方式、行为模式、设备指纹照样会触发平台的风控策略，商家的宣传口径里也承认这一点。
